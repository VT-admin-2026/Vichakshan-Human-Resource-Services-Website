# Vichakshan Human Resource Services

Premium multi-page corporate website for Vichakshan Human Resource Services — a static informational site for recruitment, staffing, and workforce management.

## Stack

- React + Vite
- React Router
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run preview` — preview production build

## Structure

```
src/
  components/   # layout, ui, and section components
  pages/        # route pages
  layouts/      # shared page shell
  data/         # content and navigation data
  hooks/        # reusable hooks
  styles/       # global CSS and design tokens
```

## Pages

- `/` Home
- `/about` About Us
- `/services` Services
- `/industries` Industries
- `/contact` Contact
- `/privacy` Privacy Policy
- `/terms` Terms & Conditions
